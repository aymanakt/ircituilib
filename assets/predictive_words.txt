# The predictive gallery's word-list source, read at startup by
# IrcitUiDictionaryIngestFile. One word per line; blank lines and `#` lines are skipped, and
# a line longer than the caller's cap is refused rather than truncated.
#
# NOT A SYSTEM DICTIONARY, and deliberately so: /usr/share/dict/words does not exist on every
# machine this repository is built on (it does not exist on the one this file was written on),
# so a demo that named it would be a demo that works only where the file happens to be. The
# list is short, checked in, and about the demo's own vocabulary -- which also means several of
# its words share a prefix with entries in the compiled-in list, so the composite's ORDER is
# observable rather than asserted.
